# Payload CMS (Toxa) — The Next-Gen Headless TypeScript CMS UI

A developer-first, dark mode open-source web showcase UI for **Payload CMS**, featuring live interactive Local / REST / GraphQL API code playground, TypeScript collection definitions, performance benchmarks, and instant CLI deployment widgets.

## ✨ Features
- **Developer-Centric Dark Mode Aesthetic**: Monochromatic pitch canvas (`#080808`), electric green accents (`#22c55e`), Space Grotesk and Fira Code typography.
- **Interactive API Playground**: Toggle between Local API (TypeScript), auto-generated REST endpoints, and typed GraphQL schemas with live response JSON.
- **Microsecond Cold-Start Benchmarks**: Direct comparison against Strapi and Contentful displaying zero HTTP overhead latency.
- **Bento Grid Architecture**: Showcasing full Next.js App Router support, Postgres/MongoDB/SQLite adapters, and field-level RBAC access control.
- **Interactive Quickstart CLI Widget**: One-click clipboard copy for `npx create-payload-app@latest` with simulated GitHub star counter.
